# Проверка на MX10

Тесты библиотеки не заменяют испытание на физическом принтере.

1. Установите непрерывную ленту, которая свободно помещается в отсек. Закройте
   FunPrint и TiMini GUI, освободив Bluetooth-соединение.
2. Проверьте `check-backend`, затем `scan` и `info --address ADDRESS`.
   Для проверенного пользователем MX10 ожидается профиль `v5g_small_203`.
3. Отправьте один пример через `print --address ADDRESS --paper continuous
   --id 123456789 --name "Роза фон Праунхайм"`. CLI-команду вводите одной строкой.
4. Проверьте ориентацию, отсутствие инверсии, читаемость имени и расстояния между
   цифрами. Фон белый, сегменты чёрные. Размер макета по умолчанию 40 × 30 мм.
5. Измерьте макет и положение на бумаге. Скорректируйте `--dpi` и
   `--offset-x-mm`, если нужно. Общая протяжка после печати может быть больше
   высоты макета, поскольку upstream добавляет выход бумаги.
6. При обрыве связи или отмене сначала посмотрите, что уже вышло из принтера.
   Не повторяйте задание автоматически. Для следующей попытки создайте новую
   сессию или отключитесь и подключитесь заново.

Режим `--paper labels` для MX10 пока должен вернуть ошибку без передачи растра.
Это ожидаемое поведение, пока не реализованы его собственные команды границ
этикетки. Не проверяйте стикеры под видом непрерывной бумаги: этот режим
не ищет зазор и может напечатать поперёк нескольких наклеек.

Для исследования калибровки понадобится подходящая лента и запись Bluetooth
обмена FunPrint: подключение, выбор обычной бумаги, выбор этикеток, калибровка,
одна печать. Самостоятельно изменять V5X-команды и отправлять их в MX10 не нужно:
это разные семейства протокола.
